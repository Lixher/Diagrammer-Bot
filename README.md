# 🤖 Diagrammer Bot for Telegram

Создавайте **интерактивные диаграммы** прямо в Telegram! Этот бот работает локально на Windows, не требует серверов и позволяет визуализировать ваши идеи с помощью **текста**, **изображений** и **связей**.

## 🧩 Ключевые Возможности

- 🧱 **Текст и Изображения:** Добавляйте текстовые и графические блоки (узлы).
- 🔗 **Связи:** Легко соединяйте блоки направленными стрелками.
- 🎨 **Две Темы:** Переключайтесь между стильной тёмной и чистой светлой темами.
- 💾 **Сохранение и Загрузка:** Создавайте, сохраняйте и загружайте несколько диаграмм.
- 🖼️ **Экспорт в PNG:** Скачивайте готовые диаграммы в высоком разрешении с водяным знаком.
- 👮 **Админ-панель:** Встроенная команда `/users` для администратора.
- 💻 **Локальная работа:** Не требует хостинга, работает прямо на вашем ПК.
- ✅ **Оптимизировано для Windows:** Полная совместимость с Windows 10 / 11.

## 🚀 Установка и Запуск (для Windows)

Всего 6 простых шагов, чтобы запустить бота на вашем компьютере.

---

### 🔹 Шаг 1: Установите Python

1.  Скачайте установщик **Python 3.11 или новее** с [официального сайта](https://www.python.org/downloads/windows/).
2.  Запустите его и **обязательно** поставьте галочку:
    > ✅ **Add Python to PATH**
3.  **Проверьте установку:** откройте командную строку (`cmd` или `PowerShell`) и введите:
    
    ```bash
    python --version
    ```
    Вы должны увидеть версию Python (например, `Python 3.11.5`).

---

### 🔹 Шаг 2: Установите Graphviz

Это "движок", который рисует диаграммы.

1.  Перейдите на [страницу загрузки Graphviz](https://graphviz.org/download/).
2.  Найдите раздел **Stable Windows install packages** и скачайте `.exe` установщик.
3.  Установите Graphviz (желательно в стандартную папку `C:\Program Files\Graphviz`).
4.  **Добавьте Graphviz в PATH:**
    -   Нажмите `Win + S` и введите "Переменные среды".
    -   Выберите "Изменение системных переменных среды".
    -   Нажмите "Переменные среды...", в нижнем окне выберите `Path` и нажмите "Изменить".
    -   Нажмите "Создать" и вставьте путь к папке `bin`: `C:\Program Files\Graphviz\bin`.
    -   Нажмите "OK" на всех окнах.
5.  **Перезапустите командную строку** и проверьте установку:
    
    ```bash
    dot -V
    ```
    Вы должны увидеть версию Graphviz.

---

### 🔹 Шаг 3: Скачайте Проект

1.  Установите [Git для Windows](https://git-scm.com/download/win), если у вас его нет.
2.  Откройте командную строку и выполните:
    
    ```bash
    git clone https://github.com/Lixher/diagrammer-bot.git
    cd diagrammer-bot
    ```
    *(Не забудь заменить `Lixher` на свой никнейм на GitHub)*

    > **Без Git:** Можно просто скачать проект как ZIP-архив со страницы репозитория и распаковать его.

---

### 🔹 Шаг 4: Настройте Виртуальное Окружение

Это хорошая практика, чтобы не засорять систему.

```bash
python -m venv venv
venv\Scripts\activate
Теперь слева в командной строке вы должны видеть (venv).
```

🔹 Шаг 5: Установите Зависимости
Проект использует несколько библиотек. Установите их одной командой:
```code
Bash
pip install -r requirements.txt
```

🔹 Шаг 6: Настройте и Запустите Бота
Найдите в Telegram бота @BotFather, создайте нового бота и получите его токен.
Откройте файл config.py в проекте и вставьте свой токен.
Запустите бота:
```code
Bash
python main.py
```
🎉 Готово! Ваш бот запущен и готов к работе в Telegram.

❗ Решение Частых Ошибок
Ошибка	Причина	Решение
graphviz.backend.ExecutableNotFound	Graphviz не установлен или не добавлен в PATH.	Выполните Шаг 2 еще раз, убедитесь, что путь в PATH правильный, и перезапустите терминал.
ModuleNotFoundError: No module named 'telegram'	Не установлены зависимости Python.	Активируйте виртуальное окружение (venv\Scripts\activate) и выполните pip install -r requirements.txt.
OSError: cannot open resource (шрифт)	Не найден системный шрифт arial.ttf.	Скачайте и установите шрифт Arial в Windows или скопируйте любой .ttf файл в папку проекта.
PermissionError: [WinError 32]	Файл диаграммы используется другой программой.	Закройте открытое изображение .png из папки diagrams перед генерацией нового.
